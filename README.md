# Калькулятор с историей вычислений

Консольный калькулятор на C++, который выполняет арифметические операции и сохраняет историю всех вычислений текущей сессии.

## Возможности

- Сложение, вычитание, умножение, деление
- Защита от деления на ноль (выбрасывается исключение)
- История всех вычислений с выражениями и результатами
- Очистка истории
- Корректная обработка некорректного ввода

## Требования

- Компилятор с поддержкой C++17 (g++ 7+, clang++ 5+, MSVC 2017+)


## Сборка и запуск


Проект использует систему автоматизации сборки CMake и полностью совместим со средой разработки Visual Studio.

### Способ 1: Через интерфейс Visual Studio (Рекомендуемый)
1. Склонируйте репозиторий или скачайте его в виде ZIP-архива и распакуйте.
2. Откройте **Visual Studio**.
3. Выберите пункт **«Открытие локальной папки»** (Open a local folder) и укажите путь к корневой папке проекта (где находится файл `CMakeLists.txt`).
4. Дождитесь автоматической генерации кэша CMake (процесс отображается в нижней панели IDE).
5. Для компиляции и запуска калькулятора нажмите комбинацию клавиш `Ctrl + F5`.

### Способ 2: Через командную строку (Автоматический скрипт)
Если вам необходимо собрать проект без открытия среды разработки:
1. Запустите файл `build.bat`, находящийся в корневом каталоге проекта.
2. Скрипт автоматически создаст директорию сборки и скомпилирует исполняемый файл.
3. Готовый файл `calculator.exe` будет доступен для запуска.

## Запуск тестов
Для проверки корректности работы калькулятора модульные тесты можно запустить двумя способами:
1. Через **Обозреватель тестов** в Visual Studio (`Тест` -> `Запуск всех тестов`).
2. Запуском скомпилированного исполняемого файла тестов `tests.exe` из папки сборки.

## Архитектура

Проект построен вокруг класса `Calculator`:

- `add(a, b)` — сложение
- `subtract(a, b)` — вычитание  
- `multiply(a, b)` — умножение
- `divide(a, b)` — деление (бросает `std::invalid_argument` при делении на 0)
- `getHistory()` — возвращает вектор всех выполненных операций
- `clearHistory()` — очищает историю
- `getHistorySize()` — количество операций в истории

Каждая операция автоматически записывает в историю строку вида `"10 + 5 = 15"` и числовой результат.
