# Калькулятор с историей вычислений

Консольный калькулятор на C++, который вычисляет математические выражения и сохраняет историю всех вычислений текущей сессии.

## Возможности

- Вычисление выражений целиком: `(8+10)*8`, `2+2*2`, `100/4-5`
- Правильный порядок операций: умножение и деление выполняются раньше сложения и вычитания
- Поддержка скобок любой вложенности
- Защита от деления на ноль
- История всех вычислений с выражениями и результатами
- Очистка истории
- Корректная обработка некорректного ввода


## Сборка и запуск

### Windows (через bat-файл)

Дважды кликни `build.bat` или запусти в терминале:

Скрипт сам найдёт Visual Studio, скомпилирует проект и создаст `calculator.exe`.

### Windows (через VS Code)

1. Открой папку проекта в VS Code
2. Установи расширение **C/C++** (Microsoft) и **CMake Tools**
3. Нажми `Ctrl+Shift+P` → `CMake: Configure`, затем `CMake: Build`
4. Запусти через терминал: `.\calculator.exe`

### Linux / macOS (через терминал)

```bash
mkdir build && cd build
cmake ..
cmake --build .
./calculator
```

## Архитектура

Проект построен вокруг класса `Calculator`:

- `calculate(expression)` — вычисляет строку-выражение, например `"(8+10)*8"`. Бросает `std::invalid_argument` при ошибке (деление на ноль, некорректный символ и т.д.)
- `getHistory()` — возвращает вектор всех выполненных вычислений
- `clearHistory()` — очищает историю
- `getHistorySize()` — количество вычислений в истории

Разбор выражений реализован методом **рекурсивного спуска**: три функции вызывают друг друга по цепочке, обеспечивая правильный приоритет операций.
