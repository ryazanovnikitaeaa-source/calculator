# Калькулятор с историей вычислений

Консольный калькулятор на C++, который выполняет арифметические операции и сохраняет историю всех вычислений текущей сессии.

## Возможности

- Сложение, вычитание, умножение, деление
- Защита от деления на ноль (выбрасывается исключение)
- История всех вычислений с выражениями и результатами
- Очистка истории
- Корректная обработка некорректного ввода

## Требования

- Компилятор с поддержкой C++17 (g++ 7+, clang++ 5+, MSVC 2017+)
- CMake 3.14+

## Сборка и запуск

```bash
# 1. Склонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/calculator.git
cd calculator

# 2. Создать папку для сборки
mkdir build
cd build

# 3. Сгенерировать файлы сборки и собрать
cmake ..
cmake --build .

# 4. Запустить программу
./calculator          # Linux/macOS
calculator.exe        # Windows
```

## Запуск тестов

```bash
# Из папки build/ (после сборки):
ctest --output-on-failure
```

Или напрямую:

```bash
./tests              # Linux/macOS
tests.exe            # Windows
```

## Архитектура

Проект построен вокруг класса `Calculator`:

- `add(a, b)` — сложение
- `subtract(a, b)` — вычитание  
- `multiply(a, b)` — умножение
- `divide(a, b)` — деление (бросает `std::invalid_argument` при делении на 0)
- `getHistory()` — возвращает вектор всех выполненных операций
- `clearHistory()` — очищает историю
- `getHistorySize()` — количество операций в истории

Каждая операция автоматически записывает в историю строку вида `"10 + 5 = 15"` и числовой результат.
